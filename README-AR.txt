طريقة البناء على GitHub Actions
1) أنشئ مستودعاً جديداً على GitHub وارفع كل هذه الملفات في جذر المستودع (بما فيها مجلد .github).
2) بعد الرفع افتح تبويب Actions ثم شغّل Build Windows EXE (أو ينفذ تلقائياً عند الرفع على main).
3) عند اكتمال البناء نزّل الملف من Artifacts باسم sales-system-exe، وفيه ملف التثبيت EXE.

للتجربة على جهازك: npm install ثم npm start (يلزم Node.js).

أماكن البيانات في نسخة الويندوز:
- قاعدة IndexedDB داخل مجلد بيانات التطبيق (AppData\Roaming\SalesSystem).
- ملف salesdata.json بجانبها، ونسخة يومية في مجلد backups (آخر 14 يوماً).
- ملفات الترخيص المخفية في ثلاثة أماكن، ولا تُمحى بضبط المصنع.

ملاحظة: ملف EXE يعمل على ويندوز فقط، وليس على الهاتف.
