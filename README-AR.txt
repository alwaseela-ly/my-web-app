منظومة المبيعات — الإصدار الاحترافي 1.1.0

## التشغيل والبناء

1. للتجربة: `npm install` ثم `npm start`.
2. لبناء نسخة Windows: `npm run dist` أو شغّل GitHub Actions.
3. ملف EXE مخصص لـ Windows.

## أبرز التحسينات

- واجهة عربية RTL عصرية ببطاقات وظلال وأزرار وأيقونات منظمة، مع الإبقاء على شريط أيقونات التنقل العلوي بنفس فكرته وترتيبه.
- نسبة التحويل المصرفي تُكتب كرقم فقط: `1` = 1%، و`0` = بدون رسوم.
- تحفظ نسبة التحويل تلقائياً وتبقى للفواتير الجديدة حتى يغيّرها المدير.
- إضافة إعدادات احترافية للفواتير بخطوط عربية مضمّنة: Noto Sans Arabic وNoto Kufi Arabic وNoto Naskh Arabic وAmiri وScheherazade، مع محاذاة يمين/وسط/يسار.
- رفع أيقونة أو شعار PNG / SVG / WebP / JPEG، مع دعم الأيقونات ذات الخلفية الشفافة وظهورها في رأس الشاشة الرئيسية دون تداخل مع اسم المتجر أو شريط الأيقونات.
- النصوص الإضافية في رأس وتذييل الفاتورة، مع معاينة وطباعة A4 وحرارية.
- إضافة 60 كود اشتراك شهري مشفراً داخل نظام التفعيل.
- ملف `monthly-subscriptions.xlsx` منفصل للبائع فقط؛ لا يُضمّن في نسخة العميل.

## طريقة استخدام أكواد الاشتراك

افتح الإعدادات ← الاشتراك والتفعيل، ثم أدخل كوداً من ملف Excel. كل كود يُستخدم مرة واحدة ويضيف شهراً كاملاً إلى المدة الحالية.

## البيانات والنسخ الاحتياطي

- تحفظ البيانات في IndexedDB ونسخة سطح المكتب في `salesdata.json`.
- توجد نسخ احتياطية يومية تلقائية لآخر 14 يوماً.
- ملفات الترخيص محفوظة في مواقع محلية متعددة كما في النسخة الأصلية.
